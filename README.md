# 🎨 InkFlow - Plateforme de Gestion pour Tatoueurs

Une application complète pour gérer votre studio de tatouage : réservations, paiements, galerie Flash, et CRM client.

## ✨ Fonctionnalités

### 🏠 Landing Page
- **Hero Section** : Présentation avec statistiques et CTA
- **Social Proof** : Témoignages clients avec notes 4.9/5
- **Features Bento Grid** : Présentation visuelle des fonctionnalités
- **Pricing** : 3 plans tarifaires (Solo, Studio, Enterprise) avec toggle mensuel/annuel
- **Process** : Guide en 4 étapes pour démarrer
- **CTA Final** : Section d'appel à l'action avec garanties
- **Footer** : Liens et réseaux sociaux

### 🔐 Authentification
- **Page de Connexion** : Login avec email/mot de passe
- **Page d'Inscription** : Création de compte avec validation
- **Compte Démo** : Test rapide sans création de compte
- **Context Auth** : Gestion globale de l'authentification avec localStorage

### 📊 Dashboard
- **Vue d'ensemble** : Métriques en temps réel
- **Projet en cours** : Card principale avec détails client
- **Revenue** : Suivi des revenus quotidiens
- **Demandes** : Nouvelles demandes de clients
- **Stock** : Alertes pour le matériel critique
- **Agenda** : Calendrier hebdomadaire interactif
- **Portfolio** : Galerie de travaux

## 🚀 Installation et Démarrage

```bash
npm install
npm run dev
```

Ouvrez http://localhost:3000

## 🎯 Navigation

- `/` - Landing page
- `/login` - Page de connexion
- `/signup` - Page d'inscription
- `/dashboard` - Dashboard (nécessite authentification)
