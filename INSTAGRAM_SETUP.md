# Connecter Instagram à Inkflow

Réponds à tes clients directement depuis Inkflow via Instagram Direct Messages.

## Prérequis

1. **Compte Instagram en mode Professionnel**
   - Paramètres → Compte → Passer en compte professionnel
   - [Comment passer en compte professionnel ?](https://help.instagram.com/502981923235522)

2. **Lier ton compte Instagram à une Page Facebook**
   - Une Page Facebook est requise pour utiliser l’API Instagram Messaging
   - Crée une Page si nécessaire dans les paramètres de ton compte professionnel

## Connexion dans Inkflow

1. Va dans **Paramètres** → onglet **Messagerie**
2. Clique sur **Connecter mon Instagram**
3. Autorise les permissions demandées (messages, profil de base)
4. Tu seras redirigé vers Inkflow une fois la connexion terminée

## Utilisation

Une fois connecté, l’onglet **Messagerie** affiche tes conversations Instagram Direct. Tu peux répondre à tes clients sans quitter l’app.

## Déconnexion

Dans Paramètres → Messagerie, clique sur **Déconnecter Instagram** pour révoquer l’accès.
