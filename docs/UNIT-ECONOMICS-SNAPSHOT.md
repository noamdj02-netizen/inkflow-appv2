# Unit economics — grille mensuelle (fondateur)

Objectif : garder la **marge** visible avant d’investir en acquisition. À remplir chaque mois (Notion ou tableur).

| Poste                             | Montant (€) | Note                        |
| --------------------------------- | ----------- | --------------------------- |
| MRR (abonnements InkFlow perçus)  |             | Stripe + exports            |
| Coûts Stripe (frais + Connect)    |             | Dashboard Stripe            |
| Supabase (plan + éventuel egress) |             | Facture Supabase            |
| Resend / e-mails                  |             |                             |
| Twilio SMS (si activé)            |             |                             |
| Vercel / domaines / autres SaaS   |             |                             |
| **Marge brute approx.**           |             | MRR − somme coûts variables |

**Indicateurs utiles**

- Coût variable moyen **par studio payant actif** = total coûts variables ÷ nombre de studios payants ce mois-là.
- Si tu fais de la pub : estimer un **CAC grossier** (dépense pub ÷ nouveaux studios payants sur la période).
